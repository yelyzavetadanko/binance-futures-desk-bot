This repository is a **safe public showcase** of a production trading system architecture and operator interface.

It is intentionally published as a **demo/vitrine**:
- includes UI/UX preview and technical positioning,
- excludes private production internals and deploy credentials,
- designed for evaluation and collaboration discussions.

---

## What is included

- Multi-page web control center preview (`docs/dashboard`)
- Runtime configuration UX examples (trading, pairs, risk, Telegram)
- Trade history / PnL presentation layer
- Public technical documentation and positioning

## What is intentionally excluded

- Production bot core implementation
- Server-side execution internals
- Live secrets and private infrastructure configuration
- Turnkey deploy package for direct reuse
